# Changelog

All notable changes to PromptBench are documented in this file.

## [0.1.0] - 2026-11-17

### Added
- Initial provider-neutral Python package.
- JSONL dataset loading and validation.
- Deterministic required- and forbidden-phrase checks.
- Python API for evaluating one case or running a dataset.
- Terminal and JSON reports.
- CLI entry point and GitHub Actions CI.
- Contribution, security, conduct, and MIT license documents.
